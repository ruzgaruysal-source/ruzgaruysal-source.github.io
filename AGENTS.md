# Rules for any AI working on this repo (Claude, Copilot, Cursor, ChatGPT, Gemini)

Owner: Rüzgar Uysal (Founder & CEO, BeVibome). Site: https://ruzgaruysal-source.github.io

## What this is
- Static site on GitHub Pages. No build step. Push to `main` = live in ~1 min.
- `/` = BeVibome store (US home products). `/ruzgaruysal/` = personal page (standalone HTML).
- `/pages/track-order/` = track page (NYC skyline: `/a/nyc-skyline.svg`).
- Videos/images in `/a/`. Keep `googlef71864de84125f64.html` (Search Console) and the IndexNow key `.txt`.

## Hard rules
1. Never commit passwords, API keys, tokens, ID numbers, addresses or anyone's company info. This repo is PUBLIC.
2. Work on a new branch and open a pull request. Never force-push `main`.
3. Change only what was asked. Do not remove or redesign features you were not asked about.
4. No prices on social media assets. No fake reviews, fake numbers or countdowns.
5. Personal page: English default, third person, "Founder & CEO", one text colour, coral (#ff8a65) only on buttons/accents, no stock names.
6. Test on a phone-width screen (390px) before opening the PR. No horizontal scroll, text never overlaps.
7. Every PR description: what changed, which files, how it was tested.
